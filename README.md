# Dein Weg. Dein Abschluss.

Infoseite des Berufskollegs Rheydt-Mülfort (Mönchengladbach): Abschluss wählen → passender Bildungsgang.

**Live:** https://bk-rheydt-muelfort.github.io/dein-weg/

- Alle Seiten werden mit `python3 tools/generate.py .` erzeugt. Inhalte (Bildungsgänge, Fotos, Infotag) stehen oben in `tools/generate.py`.
- Fotos: `assets/img/<name>-1200.webp` und `-640.webp`; neue Fotos in der Liste `PHOTOS` eintragen.
- Schrift: Dosis (SIL Open Font License), lokal eingebunden – keine Verbindung zu Google.
