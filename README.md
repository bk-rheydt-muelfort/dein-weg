# Dein Weg. Dein Abschluss.

Infoseite des Berufskollegs Rheydt-Mülfort (Mönchengladbach) mit Schulberater und Präsentation.

**Live:** https://elsen-unterricht.github.io/dein-weg/

- `index.html` – die komplette Seite. Die Bildungsgänge stehen im Script als Objekt `BG`, die Zuordnung Abschluss → Bildungsgang in `ABSCHLUESSE`.
- `assets/` – Logo, Icons, Folienbilder, PDF/PPTX zum Download, QR-Code.
